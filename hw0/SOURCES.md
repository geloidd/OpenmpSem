## Для чего

Статья - для 

Gemini - для устранения проблем при установке нужного компилятора, разрешения проблем с "особенностями" mac (например LC_NUMERIC=C, без которго запятая в 3,14 читалась как запятая)

## Где источник ошибся

Без добавления export LC_NUMERIC=C в файле конфигурации

при  make test  

FAIL: ./build/pi 1000000, потоков 1: RESULT=3.141592653590, ожидалось 3.14159265358979 ± 1e-9
make: *** [test] Error 1

Хотя тесты допускают погрешность ± 1e-9. Это происходит так как консольные утилиты macOS читают настройки региона macOS(RU) и ждут запятую(для дробного числа), и утилита обрезает дробную часть (воспринимая число просто как целое 3).

## Как проверяли
После установки переменной окружения LC_NUMERIC=C

make test завершился без ошибки

OK   ./build/pi 1000000, потоков 1: RESULT=3.141592653590
OK   ./build/pi 1000000, потоков 2: RESULT=3.141592653590
OK   ./build/pi 1000000, потоков 4: RESULT=3.141592653590
